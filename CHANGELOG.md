# Changelog

All notable changes to the "FolderPin" extension will be documented in this file.

## [0.1.1] - 2025-05-29

### Fixed
- Removed redundant quick-pick step when creating a workspace file — now asks for the workspace name directly in one prompt

---

## [0.1.0] - 2025-05-29

### Added
- Initial release of FolderPin
- Right-click context menu actions: **Pin to Workspace** and **Unpin from Workspace**
- Pinned folders are inserted at the top of the workspace file's folder list
- Automatic workspace file creation with custom naming
- Smart workspace detection — prompts to open the workspace file only when not already inside it

### Changed
- Context menu commands placed in the workspace group for cleaner Explorer menu organization
